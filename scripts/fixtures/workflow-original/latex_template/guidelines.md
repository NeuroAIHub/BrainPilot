# Acceptance fixture formatting guidelines

Use the supplied article template, retain all named sections, and keep the paper
anonymous. This fixture needs only a short manuscript. A compact booktabs table
should appear before the conclusion. Citations must use the supplied reference
library. There are no supplied figure images in this default PlotOff fixture.

The format-repair mock will request a tabular column-padding change. This is a
controlled test branch, not an independent assessment of visual quality.
