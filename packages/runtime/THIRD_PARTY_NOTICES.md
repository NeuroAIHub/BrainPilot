# PaperOrchestra

This package includes adapted prompts from Google Research's PaperOrchestra,
copyright Google LLC, under the Apache License, Version 2.0. The complete license
is provided in `PAPERORCHESTRA_LICENSE`.

Source: https://github.com/google-research/paper-orchestra
Reference commit: `ca1b3fa01c2970fc7cda32d16245db38d57b3f56`.

BrainPilot executes the default non-plotting pipeline natively in TypeScript/Pi.
Its orchestration, provider and tool bindings differ from the original Python/
Gemini implementation. The prompt source snapshot, extraction and adaptation
notes are retained with the workflow source. This is not an exact reproduction
of the upstream model configuration or benchmark results.
