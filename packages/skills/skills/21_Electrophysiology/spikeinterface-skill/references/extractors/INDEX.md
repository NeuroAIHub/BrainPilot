# SpikeInterface Extractors — Index

Leaf files for `spikeinterface.extractors` reference, split from `references/extractors-part-a.md` (recordings) and `references/extractors-part-b.md` (sorting / event / snippets / helpers). Signatures are copied verbatim from `spikeinterface/src/spikeinterface/extractors/`.

## General notes

- Every `read_*` in these files is typically generated by `define_function_from_class(source_class=<XxxRecordingExtractor>, name="read_xxx")` — the returned object is an instance of the class named in each subsection's "Return type" line.
- To import the underlying class objects (rather than the `read_*` wrapper), use `from spikeinterface.extractors.extractor_classes import ...`. Importing classes directly from `spikeinterface.extractors` is deprecated (removal in 0.105.0) and emits a `DeprecationWarning`.
- Optional dependency legend:
  - **neo**: `neo` package (required by all `neoextractors/*`; extras like `neo[ced]`, `neo[edf]`, `neo[nixio]` are noted per-format).
  - **pynwb / hdmf-zarr / h5py**: NWB extractors.
  - **mearec**: MEArec simulated files.
  - **ONE-api / ibllib / brainbox**: IBL streaming.
  - **mtscomp**: compressed IBL cbin.
  - **shybrid / hybridizer / pyyaml**: SHYBRID recording.
  - **probeinterface** is a hard dep of spikeinterface.
