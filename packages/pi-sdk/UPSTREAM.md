# Pi SDK source and security backport

This workspace republishes the compiled [@earendil-works/pi-coding-agent 0.84.2](https://www.npmjs.com/package/@earendil-works/pi-coding-agent/v/0.84.2) SDK under `@brainpilot/pi-sdk`. BrainPilot depends on its accepted 0.84.2 session and compaction behavior. The upstream release's published npm shrinkwrap pins vulnerable `undici` 8.9.0 and `brace-expansion` 5.0.9. The latest inspected upstream release, 1.0.0, still pinned vulnerable `brace-expansion` on 2026-10-02.

[`scripts/build-pi-sdk.mjs`](../../scripts/build-pi-sdk.mjs) verifies the checked-in official npm [tarball](vendor/upstream-0.84.2.tgz) against its published SHA-512 integrity and regenerates compiled files during the root `npm ci` postinstall. The source release reports Git commit `914cf1472e715297caa30db4b9535d534a9eb718`. The included MIT [`LICENSE`](LICENSE) is from that commit. Run `node scripts/build-pi-sdk.mjs --check` to verify generated files against the pinned source and patch. The generated `dist`, docs, examples, README and changelog are ignored by Git but included when npm packs this workspace.

The generated package keeps Pi's compiled code, types, documentation, assets, exports and Pi configuration. Its package identity changes to `@brainpilot/pi-sdk` and BrainPilot's workspace version. The security backport changes the direct `undici` dependency and shrinkwrap entry from 8.9.0 to 8.10.2, and the shrinkwrap entry for `brace-expansion` from 5.0.9 to 5.0.12. Those entries use npm's published resolved URLs and SHA-512 integrities. The six Pi sibling packages are pinned to 0.84.2 in the fork manifest as well as the shrinkwrap, so the monorepo and published consumers use the same Pi code. Upstream source build and publication scripts are removed because the npm tarball contains compiled output, and the repository and publish metadata point to this workspace. No Pi runtime code was edited.

This is a temporary maintained package and an additional release artifact. Publish it before `@brainpilot/runtime` when a release is approved. Reconcile its dependencies and behavior with an upstream clean release before removing it. The generated package is about 15 MB on disk and adds roughly 5 MB to the Pi package tarball; consumer installs still use npm's platform selection for optional dependencies.
