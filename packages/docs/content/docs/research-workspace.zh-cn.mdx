## 从输入开始

本地安装中的**插件 → 数据集**提供研究数据；**插件 → 知识库 → 我的知识库 / 上传论文**进入本地论文流程。数据集用于分析，建立索引的论文用于检索。

数据下载完成后，点**用于新研究**把所选数据路径加入草稿。检查路径，选择服务商和模型，说明预期产物后再发送。创建草稿不会启动模型或分析。访问与下载要求见[研究数据集](./datasets)。

## 会话文件与持久文件

会话文件保存在 `<BP_DATA_DIR>/workspaces/<session-id>/`，可复用的输入保存在 `<BP_DATA_DIR>/data/`，运行时通过 `/data/…` 访问。本地新草稿尚未创建会话时，文件面板也可以展示持久库。通过 `@` 选择文件，避免猜测路径。

打开已下载数据会在文件面板定位对应目录，不会把完整数据复制到每个对话。如果使用远程部署，文件属于服务器的数据目录。

## 核对研究结果

打开**轨迹**，选择一个步骤，再通过文件操作打开相关产物，将记录中的动作与保存的文件对应起来。内部恢复检查点不会计入用户产物数量。

核对文件是否包含预期结果，以及回答中的数值是否与文件一致。步骤有记录、任务完成或结果可下载，都不代表科学结论已经批准。如果文件在轨迹事件之后被移动或删除，应从保留的文件中恢复或重新运行必要步骤；轨迹记录本身不能代替产物。

## 停止与稍后继续

用**停止**中断当前模型和工具工作，等待取消完成后再发送修改后的请求。重新打开对话可查看已保存的历史与文件；重启或升级时保留原 BrainPilot 数据目录。

数据集分类、搜索、筛选、详情和下载范围保存在页面 URL 中，刷新及浏览器前进／后退可以返回原视图。对比选择和临时凭证不属于已保存的分析配置。

## 本地与 Cloud 的区别

本地数据集下载器和知识库准备需要后端文件系统与工具访问。托管 Cloud 会隐藏这些管理控件。Cloud 的账号、沙箱及 BrainPilotBench 贡献功能由托管服务提供，并具有独立访问控制。
