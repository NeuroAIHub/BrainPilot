以下扩展目录和工作流需要 BrainPilot 0.2.3 或更高版本，或对应源码版本。在本地安装中打开**插件 → 数据集**。托管 Cloud 应用不提供这个本机下载管理器。

## 找到适合研究的数据

按研究问题、数据集名称、数据类型或格式搜索，再结合研究主题、数据类型和获取方式筛选，或对比最多三个数据集。目录包含 48 个数据集，覆盖 15 个可交叉的研究主题，包括认知、临床神经科学、神经环路、细胞图谱、生理信号和分析方法。

详情页列出提供方、获取条件、许可和已有来源信息。选择前请阅读数据源原始页面：目录收录不代表已获得访问许可，也不代表数据适合你的研究，更不能替代提供方的引用要求。同一数据集可以计入多个研究主题。

| 获取方式 | 下一步 |
| --- | --- |
| 可直接下载 | 检查可选范围后开始下载 |
| 在数据源选择文件 | 打开数据源，在原站选择文件 |
| 需要凭证 | 先获得数据源访问权限，再填写本次下载所需凭证 |
| 需要申请 | 先完成提供方的申请流程 |

## 先下载小范围数据

1. 打开详情页；如果提供参与者或样本选项，先选择小范围数据验证流程。
2. 查看**下载准备**。在运行 BrainPilot 后端的机器上安装缺失工具，再点**重新检测**。如果修改了后端继承的 `PATH`，先重启 BrainPilot。
3. 核对所选范围和剩余磁盘空间。目录中的大小是估计值，完整数据集可能远大于样本。
4. 填写所需凭证，点**开始下载**。下载历史不保存凭证；重试需要凭证的任务时须重新填写。
5. 在**我的下载**查看进度。最多同时运行 2 个下载，排队与运行中的任务合计最多 32 个；保留最近 100 条已结束记录以及活动任务。

HTTP 选项使用内置下载器；其他选项可能需要 `wget`、DataLad 及 `git`、`git-annex`，或页面列出的提供方工具。具体要求取决于所选下载方案，与模型服务商配置无关。

## 取消、重试与校验

取消会停止当前传输；普通中断的 HTTP 文件保留为 `.part`，供后续续传。服务重启后，中断的任务会标为失败，需要手动重试。**重试**会打开原数据集与范围，检查设置后点**开始下载**再次提交。

如果下载方案包含提供方校验值，BrainPilot 会在完成前校验文件。校验失败的完整文件或 `.part` 会另存为带唯一 `.corrupt-…` 后缀的副本；下次手动重试会重新获取该文件。副本仍占用磁盘空间，不能作为已验证的研究输入。若提供方持续返回错误内容，任务仍会失败，下载器不会无限自动重试。

断点续传和校验能力取决于下载方案及提供方。下载完成不代表数据在科学上已经验证；分析前仍应核对文件头、维度、单位、参与者覆盖和数据源引用。

## 把数据用于研究

完成后点**打开数据**浏览文件，或点**用于新研究**把路径放入新草稿。检查草稿、补充研究问题后再发送；这个操作不会自动启动分析。

本地新草稿在发送第一条消息前也能浏览持久库，并通过 `@` 引用输入文件。文件与轨迹证据的用法见[研究工作区](./research-workspace)。

数据保存在运行 BrainPilot 的机器上，不在浏览器的下载文件夹中：

```text
<BP_DATA_DIR>/data/datasets/
  <dataset-id>/                    # 完整范围
  <dataset-id>--<selection-id>/     # 样本或参与者范围
  .jobs.json                      # 下载历史，不是研究输入
```

运行时对应路径为 `/data/datasets/<dataset-id>`，小范围选项有独立路径。升级时继续使用同一数据目录。**复制目录**复制的是后端机器上的路径，它可能与浏览器所在电脑的路径不同。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 缺少下载工具 | 在后端机器安装指定工具，再重新检测 |
| 网络中断 | 检查网络后重试相同范围，支持的 HTTP 文件会续传 |
| 校验失败 | 重试获取新文件；按需保留 `.corrupt-…` 副本用于排查 |
| 磁盘不足 | 释放空间或选择较小范围，计算空间时包括残留和校验失败副本 |
| 401/403 或无法访问 | 检查提供方审批与凭证；公开元数据也可能对应受限数据 |
| 队列已满 | 等待任务完成，或取消不需要的任务 |
| Cloud 显示暂不可用 | 本下载器需要本地安装；Cloud 的数据和贡献流程单独提供 |
